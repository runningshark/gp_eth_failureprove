# gp_eth · 失败复盘

> 这是一个**策略失败记录**，不是一个可交易的策略仓库。
>
> 目标：用遗传规划（GP）在 ETH 日线上找择时 alpha。
> 结果：**失败**。作者自己发现了样本外造假并杀掉了策略；本仓库在此基础上做了外部独立复核，
> 确认失败，同时量化了之后三个「替代方案」被高估了多少。

## 三句话

1. **GP 是失败的，且证据确凿。** 原始树训练 +8697.7%，留出 **−5.3%**（Sharpe 0.17，MDD 66%）；10 个随机种子留出均值 −14.8%；零假设校准 p = 0.95–1.00。报告里原来的「样本外 +5.6%」是 z-score 预热期在切分点被重置造成的伪影。
2. **趋势跟踪是唯一有真实证据的腿，但量级被高估。** 单币 ETH 2022+ 确实是 +28.3%，但对 16 个币种的独立复核显示：年化中位数 +17.1%，**没有一个品种 t > 2**；等权组合 **+17.0% / Sharpe 0.74 / 回撤 30.1% / t=1.63**。
3. **两个 4h 杠杆分支是杠杆化的 beta，不是 alpha。** 全样本 214% 对应 73.5% 回撤，2022+ 只有 +71%；短线版 77.1% 回撤、2026 年 −15.7%、**当前距峰值 −46.1%**。

另外还有一条报告漏掉的策略 `range_breakout.py`：默认阈值在 2 万根 4h 上满足率 **0.0000%**，默认参数 **0 笔交易**；修好之后 21 个参数点的回撤中位数是 **86.9%**。

## 复现

脚本会自动把这个仓库注册成 `gp_eth` 包，所以**目录叫什么都行**：

```bash
py verify/00_package_tests.py        # 27/27
py verify/01_gp_holdout.py           # GP 留出 -5.3% / -58.4%
py verify/02_intrabar_liquidation.py # 「无强平」是否收盘价作弊
py verify/03_multiasset_tsmom.py     # 16 币横截面（会联网拉 Gate.io 数据）
py verify/04_range_breakout_grid.py  # 横盘突破 21 点参数面
```

策略本体用 `main.py` 作为统一入口，**目录叫什么都行**：

```bash
py main.py                              # 列出所有可用命令
py main.py tests                        # 27/27
py main.py trend --start 2022-01-01 --btc cache_BTCUSDT_1d_3000.csv
py main.py fast4h
py main.py range_breakout
py main.py benchmarks
```

> 如果目录碰巧叫 `gp_eth`，原来的 `py -m gp_eth.tests` 写法也照样可用。

## 为什么仍然值得公开

因为**失败的过程比失败的结论更有价值**：

> 这个仓库展示了一个人如何诚实地杀掉自己的策略——从发现预热伪影，到承认 10 种子均值 −14.8%，
> 到主动写下「零假设 p = 0.95–1.00」，再到标注「不要部署 seed42 那棵树」。

绝大多数量化仓库只会把 +5.6% 的样本外截图发出来。
